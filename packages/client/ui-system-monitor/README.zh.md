# System Monitor Overlay

[English](README.md) | 中文

## 概述

`@tomato/client-ui-system-monitor` 向根作用域的 `shell.overlay` 座位贡献一个条目：一张浮层卡片，收起时停在右下角，以胶囊展示 CPU、GPU 与内存；展开后成为宿主机处理器、显卡、内存、网络、磁盘、电源与 CPU 占用最高进程的看板。帧通过 `systemMonitor` 客户端服务到达，因此卡片不持有任何传输逻辑：它注册词典、一个浮层条目与注入的快照 hook，并在收起为暂停状态或卸载时释放采样流。

<a id="what-it-draws"></a>
## 绘制内容

头部带标题、流状态圆点（`live`、`reconnecting`、`unavailable`、`paused`）、采样暂停控件与收起控件。下面依次是机型与芯片、核数、已装内存与运行时长，随后每类读数一节：处理器带覆盖保留点的迷你图、每核条形行与负载均值；显卡带迷你图与显存；内存带占用条、迷你图、可用内存与交换；网络下行与上行速率；根卷容量；电池电量、充电状态与温度压制；以及宿主机采样到的进程行，按 CPU 降序。

平台报不出的字段直接省略而不是显示为零：没有显卡读数就没有显卡一节，没有计数器就没有网络行，探针毫无结果就没有磁盘或电源一节。彻底拒绝服务的采集器会在进程列表下方点名，因此空的一节永远不会被误读成空闲机器。第一帧到达前卡片显示等待状态，收起的胶囊则回退到当前流状态，不编造数值。

<a id="placement-and-interaction"></a>
## 位置与交互

卡片浮在所有栏之上，并且因为 `shell.overlay` 覆盖整个框架而在面板切换后依然存在；该层透传指针事件，只有监视器本身接受它们。监视器有三种形态：收起的胶囊、展开的卡片，以及贴边的球。

按住胶囊或卡片的任意非控件处即可拖动，借助指针捕获跟随指针，并以 16px 边距夹在窗口内；按下后移动超过 4px 才成为拖动，原地松开仍是单击，卡片的读数区与进程行属于它们自己，不参与拖动。位置、形态、贴边方向、暂停标记存在本地存储的 `tomato.system-monitor.v1` 下，拒绝存储的浏览器只会在下次挂载时忘掉它们。卡片为 348×452 CSS 像素、胶囊宽 236 像素，正文可滚动，因此矮窗口也不会裁掉任何一节。

胶囊与卡片的关闭控件把监视器收成 44px 的球，贴在离它更近的左右一侧，半边露在边缘之外，纵向位置保持在原来的中心。球显示一个读数，即 CPU 占用，颜色按负载分档：低于 60% 为绿色、60%–85% 为琥珀色、更高为红色，暂停或还没收到帧时为中性灰。点击球按收球前的形态（胶囊或卡片）在原位置展开；窗口尺寸变化时球留在同一侧边。悬浮的右键菜单（或键盘的菜单键）提供暂停/恢复、展开（球上）、浮到桌面、隐藏浮窗与收起到侧边。

胶囊与卡片的拖动与贴合过渡为 160ms，并在 `prefers-reduced-motion: reduce` 下关闭。

暂停会释放这张卡片对共享观测流的引用，在没有其他界面持有时关闭该流；恢复则重新打开。每个标签、控件与状态文案都由插件的 `systemMonitor` 词典 namespace 拥有，并注册进随包发布的八个语言 id。

<a id="desktop-panel"></a>
## 桌面浮窗

在 macOS 上，桌面壳可以用自己的浮动窗口承载同一张卡片。该窗口无边框、以侧栏毛玻璃材质为背景保持透明、始终位于其他应用之上，并由自己的头部关闭。浮窗尺寸跟随它显示的形态：卡片为 360×480，胶囊与球为卡片宽、仅容胶囊的高度，切换时保持贴靠的那一侧与纵向中心，隐藏状态下只记住形态，下次打开才应用。关闭浮窗只保存卡片尺寸的位置。它加载带 `?surface=system-monitor` 的应用页面；插件随后标记 `<html data-system-monitor-window>`，让卡片铺满整个窗口，由 surface 样式表隐藏其后的应用框架，并通过桌面桥接接上窗口的关闭控件。只要存在该桥接，应用内卡片的头部就会多出一个浮到桌面的控件，因此浮窗只有一次点击的距离，再次按下则隐藏浮窗而不销毁它。

<a id="model-experience"></a>
## 模型体验

无。本包在浮层中绘制已经采样好的帧，不注册任何提示词、工具或会话事件。

#### KV 缓存影响

无直接影响；浮层读取浏览器状态，从不进入模型请求。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与延期工作

- **没有键盘入口**——卡片没有快捷键，也没有设置项；它随发布包挂载，只能通过自己的控件收起、暂停或移动。
- **几何尺寸固定**——卡片不可缩放，窄窗口让正文滚动而不是让各节重排。
- **除了流本身没有历史**——迷你图只覆盖客户端服务保留的 90 个点；收起卡片后只有其他界面仍在观测时才会继续采样，每次挂载都会开始一条新的序列。
- **浮窗启动的是整个应用文档**——它加载同一页面并用 CSS 隐藏框架，因此打开期间会存在第二个渲染进程与第二条观测流；专用的轻量浮窗文档留待后续。
- **触摸手势仅限标题栏**——卡片不是操作系统级窗口，无法拖出框架边缘。
- **预览就是采样帧，不是测量**——数值是宿主机为该间隔上报的结果；浮层既不平滑也不重新采样。
