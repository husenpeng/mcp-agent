# 0011. 桌面冷启动品牌开屏动画

- 状态：Accepted
- 日期：2026-10-29
- 影响范围：`apps/desktop/src/`、`apps/desktop/renderer/`、`apps/desktop/tsdown.config.ts`、`apps/desktop/tests/`

## 背景

桌面冷启动先创建主窗口但不显示，Host 就绪后才显示欢迎窗或工作区；在这段时间里屏幕上没有本应用的窗口。开屏需要在等待期建立 Tomato AI 的品牌识别。视觉方向参考《赛博朋克 2077》夜之城的雨夜街道、高楼密度、红色雾层、霓虹广告与立体交通，并以东方明珠、门形双塔等中国城市天际线地标为原型做未来化处理；不复制游戏或建筑素材，城市、地标与品牌均由本地代码生成。

## 决策

- **定位**：每次进程冷启动完整播放 7.2s 的 3D 品牌动画，不因 Host 提前就绪而缩短；播完停在终态，等 Host 就绪后交给第一个应用窗口。单实例的第二次启动、macOS Dock 重新激活不播放。
- **承载**：`app.whenReady()` 内、创建主窗口之前打开独立的无边框 `BrowserWindow`。窗口 1280×760，与主窗口同尺寸且不显式定位；`frame: false`、不可缩放/最小化/最大化/全屏、`alwaysOnTop`、Windows `skipTaskbar`，`show: false` 配合同色 `backgroundColor` 避免首帧闪白。文档是 `renderer/splash.html` 的静态页面，无 React。
- **城市**：`splash-city.ts` 用固定种子生成布局：沿街楼底层是商铺，挂中文霓虹竖招牌和广告屏；后排楼、外围街区和远景巨构组成天际线；楼体有矩形退台楼和渐收圆柱塔，楼顶有设备、桅杆或尖顶，大街上方有空中连廊。`splash-street.ts` 按楼给出层高、窗格宽度、住宅饰面（清水混凝土、小块瓷砖、顺砌红砖）和阳台标记，立面着色器与沿街几何浮雕共用这套网格，窗户与浮雕对齐。立面着色器用室内映射画出房间，办公楼按楼层分区亮灯，住宅逐窗亮灯；每栋楼只用暖白或冷白一种灯色，带色的屏幕光房间约占 2.5%。玻璃按 Fresnel 反射夜空，部分楼加细角线、楼层灯带或竖向光鳍。窗格、灯带缩到几个像素宽时改为输出平均亮度，远处立面不会闪烁。路面是湿沥青：水坑做镜面反射，其他位置做粗糙拉丝反射，叠加车道线、路灯光斑和商铺霓虹溢光；画面还有雨丝和高度雾。
- **近景细节**：窗格宽过几个像素后，立面画出构件。
  - **窗户**：住宅玻璃退进墙面 0.24m，幕墙玻璃退进 0.05m；斜视时视差露出窗洞侧壁、窗台与过梁，三者按各自朝向受街面霓虹和天光照明。窗扇与横档用铝框分格，每块玻璃略带倾角，反射逐块不同。
  - **墙面**：两格宽的预制板，带板缝、色差和窗台下的雨渍。住宅挂带圆形风扇罩和百叶的空调外机；三分之一的住宅每层有阳台板与栏杆，部分墙缝有带管卡的落水管。幕墙的窗间墙是带层间亮线的背衬玻璃，部分塔楼每三格有一道竖向铝肋。
  - **店面、屋顶与招牌**：店面有玻璃门框和条纹雨棚，门头写着中文店名和英文业态（如“星河书店 / BOOKS”），分为霓虹字、白底灯箱和未亮的字三种；一条街上的店名互不相同。屋顶有卷材分缝与映出天空的积水，屋顶设备分为冷凝机、带支腿的水箱和顶置双风扇的空调机。竖招牌和广告屏装在带边框的金属箱里，竖招牌由两根支臂挂在立面上。
  - **路面**：三条横街路口有斑马线和停止线，车道上有铸铁井盖，人行道铺砖纵横分缝，路缘石在路口断开。镜头附近的积水上，雨滴落点扩散出涟漪，并扭曲倒影。
  - **材质与路灯**：沿街浮雕、设施和路缘石的边缘倒出约 3cm 圆角；混凝土有斑驳和雨痕，钢件有锈斑和磨亮的棱，雨棚是条纹帆布，消防栓是有光泽的红漆。路灯有底座、渐细灯杆、斜撑和带发光灯罩的灯头，灯光照亮临街楼的低层墙面、浮雕、设施、汽车和飞行器，并在车漆、玻璃和金属上留下高光。

  这些细节只在近处计算，地面镜面的倒影渲染不绘制。
- **沿街几何浮雕**：大街两侧楼的临街面用真实几何承载构件，轮廓不再是光滑方盒。每层楼都有檐口和女儿墙；玻璃楼每层有挑板；阳台楼每层有阳台板、扶手、立杆与隔墙；其余住宅有窗台、空调箱，部分装折返式消防梯；约一半店面挂斜向雨棚。着色器在这些立面上不再重复绘制阳台和空调外机。
- **街道**：
  - **车流**：双向 6 车道行驶建模汽车，靠右通行；同车道同速，车身不随悬浮起伏，前灯与尾灯随车移动。车身由侧面轮廓挤出，有轮拱和下压的车头；倾斜的玻璃车厢向上收窄，有漆色 A/C 柱、黑色 B 柱和腰线亮条；圆角轮胎套在亮面轮毂上。车头是 LED 灯条，车尾是贯穿式尾灯，另有格栅、保险杠进气口、侧裙、后视镜、门把手和亮着的车牌。
  - **设施**：灯杆间有板条长椅和带盖的圆形垃圾桶，路口有带帽和出水口的消防栓、圆柱护柱和红绿灯，灯头有背板，每盏灯上有遮檐。店面前的自动售货机正面是货架上的饮料、选择键和取物口；两座公交站的灯箱装在金属箱里播放广告。
  - **电缆与灯笼**：跨街电缆两端锚在两侧临街墙面上，与镜头路径上下至少错开 6m，并避开招牌、连廊和横街；部分电缆挂着成串的红纸灯笼，灯笼有竹骨和上下深色灯帽。
- **广告内容**：竖招牌、广告屏、飞艇屏和公交站灯箱展示达人营销的不同业务模块，同一内容在城市里只出现一次。
  - 竖招牌 18 种：投流加热、相似达人、粉丝增长、竞品监测、达人报价、档期日历、达人管理、数据复盘、脚本审核、爆款追踪、达人画像、品牌安全、矩阵分发、种草投放、实时看板、议价谈判、内容共创、假粉检测。布局不放回地抽取，17 块招牌各不相同。
  - 屏幕 8 种：受众洞察、一键建联、全球达人、电子签约和 AI 达人搜索各占一块楼面屏；达人营销 ROI 屏挂在飞艇上；直播带货和达人榜单是两座公交站的灯箱。竖招牌的模块不再出现在屏幕上。
  - **可读性**：广告画面按面板比例裁切，不拉伸。招牌文字、屏幕文字与图表都保持在 Bloom 阈值以下，霓虹光晕直接画进招牌贴图，随招牌一起缩小，不会糊住笔画；只有招牌边框灯管的亮芯泛光。公交站灯箱外框和售货机正面不发光。
  - **与页面覆盖层兼容**：定格构图中，屏幕不进入 HUD 四角的括角与标注、底部坐标和品牌字标所在区域。布局完成后移除落在这些区域里的屏幕（原先压在右下角坐标下的四块楼顶屏），其他建筑与招牌不变。
  - 所有广告都不出现 Tomato 品牌。
- **地标**：广场中央是带红色竖向光鳍的渐收圆柱塔，塔顶装投影仪。四座地标环绕广场：东方明珠式电视塔（三柱、斜撑、上下两个大球、五个小球和太空舱，粉色纬线灯环）；门形双塔（“大裤衩”轮廓，两腿在冠部相连，菱形网格立面，拱门红色描边，外轮廓青色描边）；扭转超高层（圆角三角平面，向上渐收并扭转三分之一圈，转角光线形成螺旋）；开瓶器塔（进深向上收窄，顶部有梯形开口并描边）。布局为每座地标保留空地，并对定格镜头保留视线走廊：走廊内、比地标近的楼压到视线以下；定格镜头 150m 内的楼也低于镜头高度，终帧能看到完整天际线。
- **交通与赛博元素**：飞车和货运飞船是建模的，沿大街航道和三条横街航道巡航。同一航道的飞行器共用一个速度，不会互相穿过；航道两端缩小淡出后循环。车灯随飞行器移动，前灯只在镜头位于前方时变亮，尾灯只在镜头位于后方时变亮。远处街区上空有纯光点车流。大街上空悬停一艘广告飞艇；铁路横街有高架磁悬浮列车，开场滑行段从大街尽头横穿。连廊高度避开航道与飞艇，横街和铁路走廊两侧不放建筑。所有灯光常亮，不闪烁。
- **飞行器细节**：
  - **飞车**：机身是圆肩楔形，共享顶点的法线让边缘平滑过渡。带框的玻璃座舱亮着仪表光。双发动机舱有点亮的进气口唇环、暗色风扇面、尾喷环和喷口，另有滑橇、侧进气口、天线和腰线灯带。每辆飞车从漆色取一种强调色，用于灯带、唇环，以及一半飞车侧面的涂装色带。
  - **飞车着色**：蒙皮在模型空间画出环缝、腰缝和车门轮廓；镜头附近的清漆还映出峡谷两侧的窗光，显出机身曲面。
  - **货运飞船**：分格挡风玻璃、顶部导轨、集装箱瓦楞纹和强调色灯带。
  - **飞艇与磁悬浮**：飞艇蒙皮画出经向接缝与环框，屏幕上下两道接缝亮起 LED 灯带；磁悬浮车厢有板缝。
- **镜头与时序**：0–1.1s 曝光从黑渐入，城市已亮着灯；镜头沿街道低空滑行，穿过飞艇与车流后升起，6.3s 停在定格构图。位置沿穿过关键姿态的向心 Catmull-Rom 曲线按弧长前进，速度曲线 C2 连续：前 22% 以爬升峰值速度的一半匀速滑行，到 50% 平滑加速到峰值，62% 起减速，到终点时速度与减速度同时归零。目标点与视场角用自然三次样条随同一弧长比例变化，关键姿态处不再出现加速度突变。3.2s 塔顶光环与投影仪亮起，3.5s 光束开始上升。前 3.2s 不出现 Tomato 标识；广告与招牌也不使用品牌。
- **品牌揭示**：`@tomato/brand` 的 64×64 路径经 `SVGLoader` 挤出为带倒角的霓虹灯管，品牌几何不维护第二份轮廓。光束到达后标志先显出暗玻璃轮廓。点亮场用笔画栅格从光束接触点出发的测地距离计算；4.15–5.45s 点亮前沿沿笔画传播，前沿有高亮，传播完后稳定为饱和红色霓虹。3.65s 起 900 颗光粒沿光束上升、在标志下方散开，每颗在点亮前沿到达其笔画位置时落下并淡出。点亮完成后标志缓慢小幅摆动。5.65s 开始解码 Montserrat Medium 大写字标，随后显示城市连接状态。
- **后处理**：场景渲染到 4× 多重采样半浮点目标。Bloom 之前先把非有限值像素置黑并把亮度钳制到 64，单个 NaN 像素不会被 Bloom 扩散成黑块。Bloom 阈值为 1，只有灯光与霓虹泛光，墙面不会发光。调色依次做 ACES 色调映射、对比度自适应锐化（按 AMD FidelityFX CAS，邻域已覆盖全亮度范围处减弱，高光不出振铃）、暗角、暗部偏冷（乘性，纯黑仍是黑）和抖动去色带；不做色差。
- **性能**：像素比上限 2，绘制缓冲最多 2560×1520 像素，大于 1280×760 的窗口相应降低像素比。开场 0.4s 内（曝光仍从黑渐入）若多数帧间隔超过 24ms，把像素比降一次到 ×0.72，只降一次，切换时画面尚暗，看不出清晰度跳变。地面镜面反射用绘制缓冲 0.4 倍分辨率，且不绘制室内与近景细节；镜头最低视线落到 450m 外时停止更新镜面。所有着色器先异步编译，再启动时间轴；DOM 字标与 HUD 动画也等第一帧 3D 出现后才开始计时。画布每帧比对自身尺寸，窗口隐藏时完成布局也能拿到正确的绘制尺寸。
- **交接**：目标窗口（主窗或欢迎窗）显示后调用 `release()`；渲染器报告动画完成后 `setOpacity` 1→0、300ms 立方缓出，关闭 splash。渲染器在目标窗口可见后 12s 仍未报告时按完成处理，这个时长覆盖动画加着色器预热；渲染进程退出、文档加载失败立即关闭。
- **降级**：WebGL 初始化或着色器编译失败时隐藏 3D canvas 与动态字标，显示本地 `welcome-brand.svg` 静态品牌；启动握手和窗口交接不变。`prefers-reduced-motion` 直接渲染城市、地标与已点亮标志的静态终帧，400ms 后回报完成。
- **等待态**：动画结束后 1.5s 仍未就绪时，字标下方淡入左右渐隐的不确定线；3D 终帧保持构图，飞行器与列车继续巡航。
- **交互与豁免**：点击窗口或按 Esc 立即跳到 3D 终态、恢复完整字标并回报完成；开发态默认播放，`TOMATO_DESKTOP_SKIP_SPLASH=1` 跳过创建。不使用扩圈、闪白、故障闪烁或画面抖动。
- **完成握手**：`splash-api.ts` 定义单向通道 `tomato-desktop:splash-animation-done`；`preload-splash.ts` 暴露 `window.tomatoSplash.notifyAnimationDone()`；主进程只接受来自 splash 窗口主 frame 且路径为 `renderer/splash.html` 的报告，重复报告不重复启动淡出。
- **异常从属**：splash 没有独立超时。fatal/恢复对话框、强制更新进入 blocking、退出路径都会立即关闭 splash，品牌动画不排在用户必须看到的界面之前。

## 备选方案

- **二维 SVG 城市**：资源轻，但建筑没有真实遮挡、空间透视和镜头位移，无法形成城市峡谷的尺度。
- **预渲染视频**：能离线制作更复杂镜头，但增加大体积二进制资源与分辨率适配成本，也不便于复用品牌路径和控制降级。
- **外部建模资源（glTF）**：地标细节上限更高，但引入模型文件、授权与加载失败路径；程序几何把所有资源留在本地 bundle。
- **徐汇西岸实景布局**：以阿里中心 8 号楼为主角、沿黄浦江展开的版本已实现，并与本方案并排比较过；最终保留地标天际线构图，在它上面细化建筑与飞行器。
- **楼群从地面升起**：生长动画能交代“建立城市”，但整批几何同时缩放显得像模型展示，掩盖了立面和街道细节；改为已亮灯的城市从黑场渐显。
- **主窗口内首屏动画**：要等主窗创建与页面加载，盖不住最早的空白期，还要处理 vibrancy 与 Windows titlebar overlay。
- **纯等待屏**：Host 就绪即关闭，快启动时动画几乎不可见，品牌投入失去意义。
- **立即显示标识**：品牌更早出现，但削弱城市建立尺度后再揭示主标识的镜头层次。

## 后果

- 冷启动增加一个 webContents、WebGL 渲染上下文与 7.2s 的最低品牌时间；点击、Esc、reduced-motion 与开发开关提供出口。
- Three.js 进入 `@tomato/desktop` 依赖，Vite 将场景、后处理、地标与品牌几何打进本地开屏 bundle（约 758KB，gzip 约 209KB）；GPU 不可用时必须有可读的静态品牌降级。
- 场景开销集中在 GPU：在 Apple Silicon 开发机上，2560×1520 绘制缓冲每帧 10.8–17.1ms（含截图钩子的同步回读），开场街道段因镜面反射、街面几何和路灯光照最重。较弱的集成显卡依赖开场降像素比。
- 主窗口 1280×760 的几何被开屏复用；修改主窗口默认尺寸时需同步 `SPLASH_WIDTH`/`SPLASH_HEIGHT`、镜头构图与地标视线走廊。
- 字标字体复用 welcome 构建产出的 `lib/welcome/brand-font.css` 与 Montserrat 字体文件；`bundle` 先构建 welcome，再构建 `lib/splash`。
- 渲染器与 shell 之间保留一条只读单向 IPC；splash 文档没有其他 IPC、导航权限或网络访问。
- 开屏占满 1280×760 且置顶，Host 就绪前的原生对话框与强制更新窗由异常路径直接关闭开屏来保证可见。

## 未决

- 帧时间只在 Apple Silicon 上测过；Windows 集成显卡上的帧率与降级效果尚未实测，必要时可调低 `MAX_PIXEL_RATIO`、雨丝数量或关闭地面镜面。
- 程序生成的几何与着色细节在密度上接近开放世界游戏的街景，但没有手工建模资产、全局光照与贴图材质，不能与 GTA6 一类 AAA 画面逐项对等。
- 开屏的紫红夜色、青色霓虹与客户端的白/深灰表面和红橙品牌色并不一致，开屏淡出后色调会跳变；曾试做统一为品牌红橙的暖色版，尚未调完。
